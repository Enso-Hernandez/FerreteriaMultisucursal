# Skill — CRUD Simple por Capas

## Objetivo
Construir un CRUD de una tabla utilizando la arquitectura
Entidad -> Datos -> Negocio -> Presentación.

## Antes de programar
1. Leer README.md.
2. Leer AGENTS.md.
3. Leer MEMORY.md.
4. Revisar la tabla y sus atributos.
5. Revisar PK, FK y tipos de datos.
6. Presentar un plan breve antes de generar código.

## Orden de implementación
1. Crear o revisar la clase Entidad.
2. Implementar la capa Datos.
3. Implementar la capa Negocio.
4. Diseñar/conectar la capa Presentación.
5. Implementar Consultar.
6. Implementar Agregar.
7. Implementar Editar.
8. Implementar Eliminar.
9. Implementar Buscar.

## Reglas
- Utilizar SqlServer.
- Utilizar parámetros en las consultas SQL.
- No conectar Presentación directamente con SqlServer
- Mantener nombres claros y código apropiado para el nivel del curso.
- No agregar patrones o librerías no solicitadas.
- No cambiar la estructura de la base de datos.

## Cierre
1. Compilar.
2. Probar las cinco operaciones.
3. Corregir errores encontrados.
4. Registrar en MEMORY.md únicamente lo verificado.
5. Dejar el proyecto listo para versionar con Git.
