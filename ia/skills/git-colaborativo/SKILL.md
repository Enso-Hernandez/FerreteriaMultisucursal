# Skill — Git Colaborativo

## Objetivo
Cerrar un ciclo estable y compartirlo con el equipo.

## Antes del commit
1. Confirmar que el desarrollo fue probado.
2. Revisar git status.
3. Confirmar que no existen credenciales o temporales.
4. Actualizar MEMORY.md con resultados verificados.

## Versionar
1. git add .
2. Revisar git status.
3. Crear un commit descriptivo.
4. Obtener los cambios necesarios del equipo.
5. Resolver conflictos si existen.
6. Integrar únicamente código revisado.
7. Enviar los cambios a GitHub.

## Regla
No integrar a main código que no haya sido revisado y probado.
