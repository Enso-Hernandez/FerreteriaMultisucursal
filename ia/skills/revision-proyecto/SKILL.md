# Skill — Revisión del Proyecto

## Objetivo
Revisar un desarrollo antes de considerarlo terminado.

## Revisar
1. Arquitectura por capas.
2. Referencias entre proyectos.
3. Consultas parametrizadas.
4. Nombres y estructura del código.
5. Manejo básico de errores.
6. Funcionamiento solicitado.
7. Código innecesario o duplicado.
8. Cumplimiento de AGENTS.md.

## Resultado
Indicar:
- Correcto.
- Problemas encontrados.
- Cambios recomendados.
- Pruebas que todavía debe ejecutar el estudiante.

No afirmar que una prueba fue exitosa si no fue ejecutada.
